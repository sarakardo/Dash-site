بسته امن SEO/GEO دش — اکتبر ۲۰۲۶

این بسته عمداً فایل‌های اصلی طراحی و عملکرد سایت را جایگزین نمی‌کند. دو مقاله آماده انتشار و قطعات ادغام sitemap، llms و فهرست مقاله را دارد. فایل‌های موجود را کورکورانه overwrite نکن؛ راهنما را بخوان.

محتوا: دو مقاله جدید، قطعه لینک فهرست، قطعه sitemap، مدخل llms.txt، فهرست URL برای IndexNow، برنامه اجرایی SEO/GEO و چک‌لیست بعد از کامیت.

این بسته روی نسخه فعلی زنده GitHub اجرا نشده؛ بنابراین موارد ادغام باید با فایل‌های فعلی مقایسه شوند. به‌خصوص workflow را قبل از جایگزینی مقایسه کن. بستهٔ کامل سایت را جایگزین مخزن نکن.
