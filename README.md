# Dash website — MVP

این نسخه برای انتشار رایگان روی Cloudflare Pages ساخته شده است.

## قبل از انتشار
1. `dash-iran.pages.dev` را با URL واقعی پروژه جایگزین کن.
2. اطلاعات تجاری تأییدنشده را اضافه نکن.
3. بعد از گرفتن دامنه اختصاصی، canonical، sitemap و URLهای داخل JSON-LD را به دامنه اصلی تغییر بده.
4. Search Console را برای دامنه/سایت واقعی راه‌اندازی کن.
