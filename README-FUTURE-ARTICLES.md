# سیستم محتوای ماژولار دش — مقاله جدید = یک فایل

از این نسخه، محتوای «چخبر؟» از ظاهر و هسته سایت جدا شده است.

## اگر فردا یک مقاله جدید داشتیم چه می‌کنیم؟

فقط یک فایل Markdown داخل این مسیر اضافه می‌شود:

`content/articles/`

مثلاً:

`content/articles/fuel-and-driving.md`

بعد Commit/Push می‌کنی. Cloudflare با اجرای `npm run deploy` ابتدا مقاله‌ها را Build می‌کند و بعد سایت را Deploy می‌کند.

### دیگر نباید این فایل‌ها را برای مقاله جدید دست بزنیم

- `index.html`
- `style.css`
- `chekhabar/index.html`
- `sitemap.xml`
- `chekhabar/articles.json`
- صفحات مقالات قبلی

اسکریپت `build.mjs` این خروجی‌ها را خودش به‌روزرسانی می‌کند.

## قالب مقاله

```text
---
title: عنوان مقاله
slug: english-slug
category: دسته‌بندی
excerpt: توضیح کوتاه و طبیعی برای کارت و SEO
cover: /assets/editorial-road.png
published: 2026-09-09
---

## تیتر اول

متن مقاله...

## تیتر دوم

متن مقاله...
```

### قوانین مهم

1. `slug` فقط انگلیسی و با خط تیره باشد؛ مثلاً `driver-for-your-own-car`.
2. `title` عنوان واقعی مقاله باشد، نه عنوان تبلیغاتی.
3. `excerpt` یک توضیح ۱ تا ۲ جمله‌ای باشد که کاربر را برای کلیک ترغیب کند.
4. اگر مطلب بر اساس یک خبر یا گزارش بیرونی است، منبع اصلی را داخل متن با لینک مستقیم ذکر کن.
5. ادعای قانونی، آماری یا خبری را بدون منبع وارد نکن.
6. برای فارسی از فاصله و نیم‌فاصله درست استفاده کن: «می‌شود»، «به‌جای»، «در صورتی که»، «مورد نیاز».

## Build چه کار می‌کند؟

با اجرای `npm run build`:

- برای هر Markdown یک صفحه مستقل در `/chekhabar/articles/<slug>/` ساخته می‌شود.
- Title و Description تولید می‌شود.
- Canonical تولید می‌شود.
- Open Graph و Twitter Card تولید می‌شود.
- Article و Breadcrumb Schema تولید می‌شود.
- کارت مقاله به «چخبر؟» اضافه می‌شود.
- `chekhabar/articles.json` به‌روزرسانی می‌شود.
- `sitemap.xml` به‌روزرسانی می‌شود.
- مقاله‌هایی که از `content/articles/` حذف شده‌اند، صفحه تولیدشده قدیمی‌شان هم حذف می‌شود.

## نتیجه

**مقاله جدید نباید باعث بازسازی دستی سایت شود.**

منبع → تحریریه دش → یک فایل `.md` → Commit → Build → انتشار.
