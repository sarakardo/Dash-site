بسته تکمیلی انتشار و ایندکس مقاله‌های جدید دش

محتوای بسته:
- chekhabar/why-choose-dash.html
- chekhabar/how-to-find-driver-for-personal-car.html
- sitemap-additions.xml: دو ورودی که باید به sitemap.xml فعلی افزوده شوند.
- llms-additions.txt: دو ورودی که باید به llms.txt فعلی افزوده شوند.
- chekhabar-links-snippet.html: قطعه لینک برای افزودن به صفحه فهرست مقاله‌ها.
- INDEXNOW-URLS.txt: URLهای دقیق برای ارسال پس از انتشار.

ترتیب اجرا:
1. دو فایل HTML را در مسیر chekhabar/ مخزن GitHub قرار بده و Commit کن.
2. قطعه لینک را به فهرست مقاله‌های chekhabar.html اضافه کن؛ فایل موجود را با قطعه جایگزین نکن.
3. دو URL را به sitemap.xml موجود اضافه کن، داخل urlset؛ کل sitemap را جایگزین نکن.
4. دو مدخل را به llms.txt موجود اضافه کن؛ فایل موجود را حفظ کن.
5. بعد از انتشار، هر دو URL را با IndexNow اعلام کن.
6. در Google Search Console، ابتدا وضعیت URL را Inspect کن؛ اگر property تأیید شده است، درخواست ایندکس بده.

تذکر: IndexNow برای گوگل جایگزین Google Search Console نیست. ارسال URL یا درخواست ایندکس تضمین نمی‌کند که گوگل صفحه را ایندکس کند.
